# Тестирование

Запускайте проверки из корня репозитория на macOS с Xcode 26+, Python 3 и Node.js.

## Автоматические проверки

```sh
scripts/test.sh
scripts/build-app.sh release
scripts/verify-release.sh
```

Скрипт запускает Swift-тесты, проверку локализаций, CLI и адаптеров JavaScript/Python. Проверка сборки сверяет состав ZIP и подпись извлечённого приложения. [GitHub Actions](../../.github/workflows/ci.yml) также собирает DMG.

## Проверка интерфейса

Извлеките ZIP во временный каталог и запустите экспорт интерфейса в графической сессии macOS:

```sh
si_notch_check_dir="$(mktemp -d /tmp/si-notch-check.XXXXXX)"
ditto -x -k build/si-notch.zip "$si_notch_check_dir"
"$si_notch_check_dir/si-notch.app/Contents/MacOS/si-notch" --qa-export "$si_notch_check_dir/qa"
```

Экспортёр проверяет геометрию окна, компоновку, состояния сессий, прозрачность и IPC. В указанном каталоге сохраняются отчёт, снимки и звуковые образцы. Просмотрите снимки на трёх языках и состояния питомцев в обоих масштабах экрана.

Добавьте `--qa-display-only`, чтобы проверить видимость нативной панели при наличии сессий и сохранить раздел Display на трёх языках, включая содержимое за пределами прокрутки. Этот режим не запускает службы агентов.

Добавьте `--qa-interaction-only` для проверки наведения через нативный обработчик без отправки ввода на рабочий стол. На расстоянии даже 0,5 pt ниже видимого контура панель не должна открываться. Прозрачные углы, непрерывный проход курсора и перетаскивание окна также не должны её раскрывать. Остановка на самой чёлке на 180 мс открывает панель; увеличенная задержка действует при входе с любой стороны. Изменение геометрии под неподвижным курсором не считается наведением. В полноэкранном режиме область открытия ограничена физическим вырезом, а на экране без него — верхними 3 pt по центру. Эти проверки не подтверждают субъективное ощущение наведения на реальном устройстве.

Статические снимки не измеряют плавность анимации или частоту кадров композитора. Вручную проверьте наведение, закрытие, Mission Control, полноэкранные приложения и смену дисплеев. Прослушайте сигналы через нужный аудиовыход.

## Установка обновлений

Для извлечённого выше приложения выполните:

```sh
python3 scripts/smoke-update.py "$si_notch_check_dir/si-notch.app"
```

Проверка требует графической сессии macOS. Она создаёт временные подписанные приложения, проверяет замену, запуск и откат, а также отказ от изменённого архива.

## Файлы релиза

```sh
scripts/build-dmg.sh
```

Откройте DMG и проверьте приложение и ссылку Applications. Сверьте скачанные файлы с `SHA256SUMS` релиза.

Покрытие интеграций и ограничения перечислены в [статусе функций](parity.md). Подготовка подписанного релиза описана в [инструкции обновлений](updates.md#выпуск-версии).

Режим `--qa-history-only` показывает список Истории, запись и настройки на трёх языках. До запуска служб он создаёт отдельный временный архив, проверяет сохранность после очистки Done и повторного открытия хранилища, затем очищает только тестовый архив. Рабочая папка истории пользователя не читается и не очищается.
