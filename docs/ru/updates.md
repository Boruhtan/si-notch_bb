# Обновления

Приложение проверяет GitHub Releases при запуске и каждые шесть часов. В **Настройки → О приложении** можно отключить фоновую проверку, выбрать стабильный или бета-канал и проверить вручную. Новая версия отображается там же и в меню строки состояния. Установка — по кнопке **Установить и перезапустить**. Настройки приложения и агентов сохраняются.

Для установки используется DMG, для обновлений — ZIP и `update.json`. Проверяются подпись Ed25519, размер и SHA-256 архива, идентификатор приложения, версия, номер сборки и подпись кода. При ошибке замены или запуска восстанавливается предыдущая версия. Постоянный привилегированный помощник не устанавливается.

Обновления загружаются из публичных Releases этого репозитория без аккаунта GitHub. В сборках используется ad hoc подпись; Developer ID и notarization пока нет.

## Выпуск версии

Измените `version` и `build` в `release.json`, добавьте заметки и отправьте коммит. Для беты используйте суффикс `-beta.1`. Команды сборки и публикации — в [английской инструкции](../updates.md#publish-a-release).

Опишите пользовательские исправления на английском в `docs/release-VERSION.md`. Один и тот же файл используется для GitHub Releases и окна обновления.

Закрытый ключ Ed25519 хранится вне репозитория. Сохраните резервную копию; публичный ключ закреплён в приложении. Не добавляйте закрытый ключ в Git или файлы релиза. Бета не заменяет последний стабильный релиз.

[GitHub Actions](../../.github/workflows/ci.yml) запускает тесты, проверяет ZIP и собирает DMG при каждом push и pull request. Подпись и публикация выполняются локально ключом разработчика. В приложение не встраивается токен GitHub.
