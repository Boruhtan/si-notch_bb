# Разрешения Claude

Необязательный обработчик показывает небольшой запрос инструмента в si-notch и возвращает Claude одно решение: разрешить или отказать. Обычные hooks статуса этого не делают.

Добавьте [пример конфигурации](../examples/claude-permissions.json) в настройки Claude, заменив абсолютные пути. Замените только существующий наблюдающий обработчик si-notch для `PermissionRequest`; остальные hooks сохраните. Два обработчика si-notch одновременно могут отменять ожидающую карточку. Проверьте запись через `/hooks` в Claude.

Поддерживаются Bash, Read, Write, Edit, MultiEdit и NotebookEdit. Полный компактный ввод должен укладываться в 240 символов. Большие запросы и интерактивные инструменты остаются в интерфейсе Claude.

Каждый запрос получает новый ID и срок ожидания 70 секунд. Тайм-аут, отмена, отсутствие приложения или неверный ответ возвращают управление обычному запросу Claude без решения. Постоянные правила доступа не добавляются.

Разрешение, отказ, соответствие ID и ошибки покрыты тестовыми сценариями. Реальный запрос разрешения Claude по этому пути ещё не проверен.
