# Статус функций

Функции и покрытие проверками для 0.4.10 на Apple Silicon. Автоматические тесты адаптеров используют подготовленные входные данные; они не подтверждают совместимость со всеми версиями агентов или полный ход модели.

| Функция | Доступность и проверка |
| --- | --- |
| Раскрытие панели | Наведение, закрытие с задержкой и автоматическое раскрытие при текущем запросе ответа. Геометрия, таймеры, отмена и обработка запросов покрыты тестами; удобство наведения требует ручной проверки. |
| Переход к сессии | Открывает задачу Codex или исходное приложение. Маршрутизация и обработка ошибок проверены; выбор конкретной вкладки терминала не поддерживается. |
| Codex Desktop | Данные сессии через локальный IPC. Проверены доставка событий и восстановление сессии после перезапуска. Reasoning текущего хода и пустые старые поля покрыты регрессией; проверены данные реальной активной сессии. |
| Codex CLI | Обнаружение локальных сессий и hooks. Проверены события жизненного цикла и подключение hooks. |
| Pi | Интеграция расширения проверена с Pi 1.2.0, локальной mock-моделью и настоящим инструментом shell. |
| OpenCode | Загрузка плагина и начало/завершение сессии проверены с 2.0.32. Поиск helper покрыт тестами; события инструментов и разрешений во время хода модели ещё не проверены. |
| Hermes | На одном удалённом Mac проверены ходы модели через API, параллельные сессии, текст задачи/ответа и события terminal. Установка и разделение профилей покрыты тестами. Другие версии и способы запуска пока не проверены. |
| Claude Code, Gemini CLI, Copilot CLI, Cursor | Слияние настроек, резервные копии и события hooks покрыты тестами. Полные ходы модели ещё не проверены. |
| Свой API | Проверены доставка, дубли, тайм-ауты и запрос/ответ. |
| SSH | На одном удалённом Mac проверены forwarding и доставка событий. Независимые туннели, проверка SSH, сохранение профилей и миграция покрыты тестами. В живом beta-интерфейсе проверены три профиля, инструменты и завершение. |
| Интерфейс | Компоновка, состояния сессий, прозрачность, питомцы и три языка покрыты тестами. |
| Настройки отображения | Показ при наличии сессий, ручное открытие, сохранение завершённых задач, сброс раздела и фиксированная ширина свёрнутой чёлки покрыты автоматизированными проверками. Видимость нативной панели и снимки настроек проверяются на локальных данных; сочетания физических дисплеев и полноэкранных режимов требуют ручной проверки. |
| Метаданные сессий | Модель и reasoning видны без раскрытия карточки. Все шесть переключателей проверяются на снимках. Плагин Hermes 1.6 использует нативные параметры запроса, каталог сессии, результаты todo_list и события субагентов; Pi и OpenCode передают доступные сведения о модели. Отсутствующие данные не подменяются. |
| Звуки | Проверены уровни, затухание, выключатели, устранение дублей и параллельные сессии. |
| Лимиты Codex | Проверены запросы CLI только для чтения и ручное обновление. |
| Обновления | Проверены каналы stable/beta, подпись Ed25519, замена, запуск и откат. Сборки подписаны ad hoc, без notarization. |

## Ручная проверка

Физический аудиовыход, удобство наведения, Mission Control, все сочетания нескольких мониторов, экранов без чёлки и полноэкранного режима, а также отображение на macOS 14–15 требуют ручной проверки. Статические снимки не измеряют частоту кадров композитора.

## Не поддерживается

Переход к конкретной вкладке терминала, автоматический тихий режим для Focus, блокировки и демонстрации экрана, Bark, Docker relay, Claude Desktop/Cowork и лимиты аккаунтов других провайдеров.
