# Feature status

Available features and verification scope for 0.4.26 on Apple Silicon. Automated adapter tests use controlled inputs; they do not establish compatibility with every agent version or a complete model session.

| Feature | Availability and verification |
| --- | --- |
| External display capsule | Displays without a physical notch use a 64 × 30 pt capsule below the menu bar at the right edge. Expansion retains the top-right anchor and shares the existing task panel. Native window bounds, opening/closing traces and return to automatic selection were checked on a built-in Retina display and a Samsung S22D390 at 1920 × 1080 / 60 Hz. Geometry, reversal and transparent-corner hit testing have regression coverage. Physical lid-close transitions, fullscreen reveal on the external display and subjective hover behavior remain manual checks. |
| Menu icon | Vector template portraits follow the selected cat, robot, sprout or ghost. All four icons were inspected on light/dark backgrounds at native and enlarged sizes. The status item follows companion preference changes without restarting; the system controls its menu-bar tint. |
| About companion | The cat uses the same click reaction as the notch companion. The reaction was manually confirmed in the installed local build. |
| Panel interaction | Hover activation, delayed dismissal and automatic expansion for active input requests. Tabs, session details and expanded remote groups adapt to their content while navigation stays at the top; scrolling is bounded by the configured/display limit. Native spring motion has frame traces for opening, closing, fixed top alignment and rapid reversal, plus Reduce Motion coverage. Static captures and geometry traces do not establish compositor frame rate. |
| Hover intent | Opening requires contact with the drawn contour and a stationary pause of at least 180 ms. The former 20 pt approach strip and immediate upward-entry path are removed. Contour boundaries, continued movement, drag suppression, geometry-only entry, timer cancellation and fullscreen reentry have automated regression coverage. Release-bundle NSWindow fixtures verified pauses 0.5–20 pt below the edge, transparent shoulders, dragging, crossing, brief contact, deliberate opening and exit dismissal through native tracking. Hover behavior was manually confirmed in the installed local build. The narrowed fullscreen target across all displays/players still requires manual validation. |
| Content resizing | Clear removes finished cards in one layout update and preserves an open panel, including session-only mode. A shrinking panel retains the current pointer interaction until the pointer reaches the new surface or leaves the previous one; explicit collapse clears this retention immediately. These cases have native-window regression coverage. Opening, closing and content resizing use separate spring profiles, preserving velocity and the current transition during measurement updates. The revised motion feel awaits manual confirmation. |
| Session navigation | Opens Codex task links or the originating app. Routing and failure handling are tested; selecting a specific terminal tab is not supported. |
| Agent status | SSH transport, profile presence and task activity are displayed separately. A connected host does not make saved profiles online. Plugin 1.8 sends presence every 30 seconds and stops on native unload. Profile isolation, idle recovery, completion and transport loss have regression coverage; a real Lane task, more than three minutes of heartbeat delivery, app restart recovery and automatic recovery after an owned SSH tunnel interruption were verified. |
| Codex Desktop | Session details over local IPC. Live event delivery and session recovery after restart are tested. Local discovery without lifecycle logs, twelve parallel subscriptions and suppression of completed-history replay have socket-level regression coverage. Current-turn reasoning metadata and null legacy fields have regression coverage; the actual active session was checked. |
| Background memory tasks | The two observed Codex memory-consolidation prompt signatures remain visible with a background-memory label. Classification and ordinary-task negative cases have regression coverage. Other internal job formats remain unclassified. |
| Codex CLI | Local session detection and hooks. Live lifecycle events and hook setup are tested. With CLI 0.161.0, a real conversation was resumed after process exit with hooks disabled for that invocation; Working → Done was verified in the installed app. Resumed rollouts in old date directories, more than sixteen active files, native file-event delivery and null parent metadata have regression coverage. |
| Native permissions | Codex PermissionRequest hooks show the complete bounded tool input and return one decision for the matching request before its deadline. Real Allow once, Deny and timeout fallback were verified with CLI 0.161.0 and the installed beta. A stale Desktop status cannot remove a live request. Only confirmed manual-review turn metadata enables the bridge; auto-review, noninteractive or granular policies, missing/mismatched metadata and unknown transcript formats defer without a native prompt. Unsupported, oversized, expired or disconnected requests fall back to the originating app; other request types and providers are not established by this test. |
| Local ChatGPT Work | Shares local hooks and Desktop observation when orchestration and execution are local. Native product metadata and a complete real local Work turn were verified in the installed app with Desktop 26.1013.40934. The chat ran /bin/sleep 20, returned SI_NOTCH_WORK_OK and changed from Working to Done while retaining its Work label and briefcase icon beside an ordinary Codex card. Metadata preservation and product classification have regression coverage. Cloud Work and dots are outside this change's scope. |
| Pi | Extension integration tested with Pi 1.2.0, a local mock model and a real shell tool. |
| OpenCode | Plugin loading and session start/end tested with 2.0.32. Helper discovery has automated coverage; model tool and permission events remain unverified. |
| Hermes | Remote API model turns, parallel sessions, task/final text and terminal events verified on one macOS host. Plugin setup and profile isolation have automated coverage. Live parent/child model and reasoning, todo progress and child completion were checked. Background children retain their own lifecycle after a parent turn; retention and expiry have regression coverage. Other agent versions and entry points remain unverified. |
| Claude Code, Gemini CLI, Copilot CLI, Cursor | Configuration merging, backups and hook events have automated coverage. Complete model sessions remain unverified. |
| Custom API | Event delivery, duplicates, timeouts and request/reply are tested. |
| SSH | External-host forwarding and relay delivery verified on one macOS host. Multiple independent tunnel controllers, SSH checks, saved profiles and migration have automated coverage. Recovery after a rejected forward preserves only a private, refused, unheld socket; repeated reconnects and refusal to move active or unsafe sockets have automated coverage. Tunnel lifetime follows the application's input pipe, with EOF/disconnect coverage. Explicit Connect is remembered for launch after local IPC starts; Disconnect clears that intent. Restart, shutdown preservation and opt-out have automated coverage. Three live beta profile cards, tool activity and completion were checked in the actual UI. |
| History | Local requests, public replies and available command text persist independently of live cards. Restart, count/byte limits, redaction, source selection, duplicate updates, buffered-write clearing and pending-request isolation have automated coverage. Native list, detail and settings captures use isolated fixtures in three languages. Commands omitted by an integration cannot be reconstructed; complete live coverage across every provider remains unverified. |
| History status | Status belongs to the archived turn and terminal states cannot be reopened by late text or tool events. On startup, a utility-queue pass over bounded local Codex rollout tails corrects existing records with an exact completion or cancellation marker; missing evidence is left unchanged, and historical sessions are not imported. Status icons have short text labels, while background memory tasks retain their originating agent beside a neutral memory icon. Regression tests cover turn isolation, persistence and reconciliation without a live session. |
| Interface | Layout, session states, transparency, companions and three languages have automated coverage. |
| Display preferences | Session-only visibility is experimental and off by default. Fresh/reset defaults, manual opening, completed-task retention, scoped default reset and fixed compact width have automated coverage. Native panel visibility and settings bitmap exports are checked with local fixtures; physical display and fullscreen combinations still require manual validation. |
| Fullscreen | The installed beta hid during native fullscreen and AVKit fullscreen video on one built-in display. Chrome native fullscreen with separate toolbar/content windows was also checked live; the panel hid and returned after exit. Deliberate hover reveal and dismissal were observed live in native fullscreen. Window-bounds fallback covers players without presentation flags; a display-filling maximized window with an auto-hidden Dock can also qualify. Display hotplug and return to the built-in screen were checked. Full two-display behavior, hover above an AVKit shielding window and all browser/player combinations remain manual checks. |
| Session metadata | Model and reasoning are visible on unexpanded cards. All six detail switches have bitmap checks. Hermes plugin 1.7 uses native request metadata, session cwd, todo-list results and subagent hooks; Pi and OpenCode supply available model metadata. Supplied metadata and missing fields remain distinct. |
| Sounds | Levels, fades, mute controls, duplicate suppression and parallel sessions are tested. |
| Codex account limits | App-owned cached snapshots refresh at launch, every five minutes and after wake; opening Usage refreshes an old reading. Read-only RPC, retained readings on error and signed-out invalidation have regression coverage. |
| Plugin announcements | Signed optional release metadata and bundled installation links appear in About and the menu bar, with new/updated labels in three languages. Remote installed versions are not inferred from release metadata. |
| Session and task tokens | A private v2 journal records native Codex/Pi request identities and Hermes request hooks. Tasks follow explicit root/parent turns; Pi uses its message graph. Grouping/undo, input/output and cache/reasoning subsets, History and live-card links are implemented without dollar conversion. A private migration retained 205 sessions; an independent calculation matched all numeric fields and turn links for 8,159 real requests, including 1,673 child requests. Deduplication, conflicting IDs, late/reused children, missing/zero data, storage failures and commit acknowledgements have regression coverage. Native fixtures cover three languages. A real remote parent plus child matched native per-model counters for all five requests (89,816 tokens), including auxiliary usage; 15 repeated deliveries changed no totals. Physical VoiceOver/navigation remains unverified; older remote usage and absent parent links cannot be reconstructed. |
| Updates | Stable/beta selection, Ed25519 verification, replacement, launch and rollback are tested. Builds are ad hoc signed and not notarized. |

The current SSH reconnect policy keeps retrying transient outages with a delay capped at 30 seconds and resets the delay after a confirmed forward. Long outages, repeated disconnects, cancellation, transient recovery failures, authentication failures and host-key failures have automated coverage. The installed local build recovered from four consecutive owned tunnel interruptions on Lane in 3.0–3.8 seconds each; all eight saved Hermes profiles resumed presence. A real trainer session was visible and updated after reconnecting the previous build. Long physical network outages and sleep/wake recovery with the new build remain unverified on hardware.

## Manual validation

Physical audio output, hover feel, Mission Control, all multi-monitor/no-notch/fullscreen combinations and macOS 14–15 rendering require manual validation. Static screenshots do not measure compositor frame rate.

## Not supported

Exact terminal-tab navigation, automatic quiet mode for Focus/lock/screen sharing, Bark, Docker relay, Claude Desktop/Cowork and other providers' account limits.
