# 功能状态

以下为 0.4.16-beta.1 在 Apple Silicon 上的功能及验证范围。适配器自动测试使用预设输入，不代表兼容所有智能体版本或已完成真实模型会话测试。

| 功能 | 可用性与验证范围 |
| --- | --- |
| 关于页面宠物 | 猫咪使用与刘海宠物相同的点击反应。已在安装的本地版本中手动确认该反应。 |
| 面板交互 | 悬停展开、延迟收起，以及收到当前输入请求时自动展开。标签页、会话详情和远程分组按实测内容调整高度，导航固定在顶部；达到配置或屏幕高度限制后才滚动。原生弹簧动画已有展开、收起、顶部固定及快速反向的几何轨迹，并覆盖减少动态效果设置。静态截图和几何轨迹不能证明合成器帧率。 |
| 会话导航 | 打开 Codex 任务链接或来源应用。路由和错误处理已测试，不支持选择指定终端标签页。 |
| 代理状态 | SSH 传输、配置在线状态和任务活动分别显示。已连接的主机不会自动使已保存配置上线。插件 1.8 每 30 秒发送心跳，并在原生卸载时停止。配置隔离、空闲恢复、任务完成及传输中断均有回归测试；已验证真实 Lane 任务、超过三分钟的心跳、应用重启恢复，以及应用自有 SSH 隧道中断后的自动恢复。 |
| Codex Desktop | 通过本地 IPC 获取会话详情。已测试真实事件接收及重启后的恢复。无需生命周期日志的本地发现、十二个并行订阅及不重复显示已完成历史记录均有真实套接字回归测试。当前轮次推理模式及旧字段为空的情况有回归测试，并已核验真实活动会话的数据。 |
| Codex CLI | 本地会话发现及 hooks。已测试真实生命周期事件和 hook 配置。在 CLI 0.161.0 中，已在进程退出后恢复真实会话，仅对该次启动禁用 hooks；在已安装应用中核验了 Working → Done。旧日期目录中的会话恢复、超过十六个活动文件、原生文件事件及空父会话字段均有回归测试。 |
| 原生权限 | Codex PermissionRequest hook 在大小限制内显示完整工具输入，并在截止时间前返回绑定到该请求的一次性决定。已使用 CLI 0.161.0 和安装的 beta 验证真实的允许一次、拒绝及超时回退。过时的 Desktop 状态不会移除当前请求。只有确认当前轮次使用人工审核时才显示提示；自动审核、非交互或细粒度策略、缺失或不匹配的元数据以及未知记录格式均直接交回 Codex，不显示原生提示。不支持、过大、过期或断开连接的请求回退到原应用；其他请求类型和提供者不在此次验证范围内。 |
| 本地 ChatGPT Work | 当任务协调与执行都在本地时，共用本地 hooks 和 Desktop 观察机制。已在安装的应用及 Desktop 26.1013.40934 中核验原生元数据和完整真实本地 Work 轮次。聊天执行 /bin/sleep 20，返回 SI_NOTCH_WORK_OK，并从 Working 变为 Done；在普通 Codex 卡片旁始终保留 Work 标签和公文包图标。元数据保留及产品识别均有回归测试。云端 Work 和 dots 不在本次更改范围内。 |
| Pi | 扩展集成已在 Pi 1.2.0 中通过本地模拟模型和真实 shell 工具测试。 |
| OpenCode | 插件加载及会话开始、结束已在 2.0.32 中测试。helper 查找已有自动测试；模型工具和权限事件尚未验证。 |
| Hermes | 已在一台远程 Mac 上验证 API 模型任务、并行会话、任务及回答文本和 terminal 事件。插件安装与配置隔离有自动化测试；已在真实界面核验父会话及子代理的模型、推理模式、todo 进度与子代理完成状态。父轮次结束后，后台子代理保留独立生命周期；保留和超时行为有回归测试。其他版本和入口尚未验证。 |
| Claude Code、Gemini CLI、Copilot CLI、Cursor | 配置合并、备份和 hook 事件已有自动测试，完整模型会话尚未验证。 |
| 自定义 API | 已测试事件传输、重复事件、超时及请求/响应。 |
| SSH | 已在一台远程 Mac 上验证套接字转发与事件传输。独立隧道、SSH 检查、配置保存与迁移有自动化测试；已在真实 beta 界面验证三个配置、工具活动与完成状态。 |
| 界面 | 布局、会话状态、透明度、伙伴和三种语言已有自动测试。 |
| 显示设置 | 仅在有会话时显示、手动打开、保留已完成任务、按分区恢复默认设置和固定收起宽度均有自动化测试。原生面板显示状态和设置截图使用本地数据验证；实体显示器与全屏模式的组合仍需手动验证。 |
| 全屏 | 已安装的 beta 在内置屏幕的原生全屏和 AVKit 全屏视频中隐藏；在原生全屏中实际观察到有意悬停展开及离开后隐藏。对于不设置系统全屏标志的播放器，使用窗口边界判断；Dock 自动隐藏且铺满屏幕的最大化窗口也可能符合条件。已检查显示器热插拔及返回内置屏幕。完整双屏行为、AVKit 保护窗口上方的悬停以及所有浏览器和播放器组合仍需手动检查。 |

| 提示音 | 已测试音量、淡出、静音控制、重复抑制和并行会话。 |
| Codex 账户限额 | 已测试只读 CLI 请求及手动刷新。 |
| 更新 | 已测试稳定版/测试版筛选、Ed25519 验证、替换、启动及回滚。构建采用 ad hoc 签名，尚未公证。 |

## 手动验证

实际音频输出、悬停手感、Mission Control、多显示器、无刘海及全屏组合，还有 macOS 14–15 的显示效果需要手动验证。静态截图不能测量合成器帧率。

## 不支持的功能

选择指定终端标签页、根据专注模式、锁屏或屏幕共享自动静音、Bark、Docker 中继、Claude Desktop/Cowork，以及其他提供者的账户限额。
