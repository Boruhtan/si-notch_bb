# 功能状态

以下为 0.4.6 在 Apple Silicon 上的功能及验证范围。适配器自动测试使用预设输入，不代表兼容所有智能体版本或已完成真实模型会话测试。

| 功能 | 可用性与验证范围 |
| --- | --- |
| 面板交互 | 悬停展开、延迟收起，以及收到当前输入请求时自动展开。几何、计时器、取消和请求处理已有自动测试；悬停手感需要手动检查。 |
| 会话导航 | 打开 Codex 任务链接或来源应用。路由和错误处理已测试，不支持选择指定终端标签页。 |
| Codex Desktop | 通过本地 IPC 获取会话详情。已测试真实事件接收及重启后的会话恢复。 |
| Codex CLI | 本地会话发现及 hooks。已测试真实生命周期事件和 hook 配置。 |
| Pi | 扩展集成已在 Pi 1.2.0 中通过本地模拟模型和真实 shell 工具测试。 |
| OpenCode | 插件加载及会话开始、结束已在 2.0.32 中测试。helper 查找已有自动测试；模型工具和权限事件尚未验证。 |
| Hermes | 已测试插件发现、配置和事件映射，完整模型会话尚未验证。 |
| Claude Code、Gemini CLI、Copilot CLI、Cursor | 配置合并、备份和 hook 事件已有自动测试，完整模型会话尚未验证。 |
| 自定义 API | 已测试事件传输、重复事件、超时及请求/响应。 |
| SSH | 已通过隔离的本地 SSH 服务器测试套接字转发和中继确认，外部主机尚未验证。 |
| 界面 | 布局、会话状态、透明度、伙伴和三种语言已有自动测试。 |
| 提示音 | 已测试音量、淡出、静音控制、重复抑制和并行会话。 |
| Codex 账户限额 | 已测试只读 CLI 请求及手动刷新。 |
| 更新 | 已测试稳定版/测试版筛选、Ed25519 验证、替换、启动及回滚。构建采用 ad hoc 签名，尚未公证。 |

## 手动验证

实际音频输出、悬停手感、Mission Control、多显示器、无刘海及全屏组合，还有 macOS 14–15 的显示效果需要手动验证。静态截图不能测量合成器帧率。

## 不支持的功能

选择指定终端标签页、根据专注模式、锁屏或屏幕共享自动静音、Bark、Docker 中继、Claude Desktop/Cowork，以及其他提供者的账户限额。

[测试说明](verification.md)。
