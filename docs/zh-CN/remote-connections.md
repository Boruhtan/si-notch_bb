# SSH 连接

**设置 → Remote SSH** 支持多个独立命名的连接。添加连接并填写名称、SSH 主机或别名。旧版单主机设置会迁移，但不会自动连接。

**检查连接** 使用现有密钥和 `known_hosts` 验证 SSH 登录，不创建隧道、不安装文件，也不验证服务器的转发策略。**连接** 启动反向 Unix 套接字转发并启用“启动时自动连接”；**断开连接** 停止隧道并关闭自动重连。退出应用保留此选择。连接失败后也可单独更改自动连接选项。升级后，旧连接需要点击一次连接或勾选启动选项；新连接默认不自动启动。修改主机或套接字前需先断开。两个活动连接不能使用相同的主机和套接字路径。

**Agents** 中每个连接显示为可折叠的组，其下列出配置。可随时重命名，或取消 **在 Agents 中显示**。删除连接会关闭隧道并删除本地设置，不会卸载远程插件。若需禁用插件，请先取消选择配置并应用更改。

## Hermes 配置

1. 先建立可信的 SSH 密钥登录。应用不会接受未知主机密钥或询问密码。
2. 点击 **检查配置**。应用通过 Hermes 现有 Python 环境读取配置名称与插件元数据，不返回凭据、对话或配置内容。
3. 选择配置、编辑显示名称，并按需启用 **显示任务与助手消息**。非标准安装可修改高级路径。
4. 点击 **预览更改**，查看配置及文件数量，再点击 **应用插件更改**。选择或远程设置改变后需重新预览。备份保留在远程主机，结果会显示备份目录。
5. 使用检查得到的绝对套接字路径并点击 **连接**。若先安装插件再连接，配置的下次任务会提供新事件。

设置会安装内置观察插件及中继，保留其他插件设置和 hooks，并请求 Hermes 重新加载插件。未运行网关的配置将在下次启动时加载。安装中断后应先重新检查配置，不能盲目重复应用。

配置没有活动任务时仍会列出。Online 表示最近收到事件，不能证明安静的进程仍在运行。SSH 隧道连接成功也不等于配置处于活动状态。

## 事件与隐私

插件发送会话状态、工具名称、调用开始、结束及失败事件，以及等待输入的通知。可选文本包含简短任务、可见助手更新与最终回答；新配置默认关闭文本共享。任务描述最多 1600 字符，更新与回答最多 4000 字符。不传输工具参数、结果、历史或私密推理。批准事件仅用于通知，插件不会自动批准。

配置身份与会话 ID 经过哈希，以区分主机和配置。分组及显示名称由本地设置决定。展开会话卡片可查看活动记录和已完成的工具调用。

## 其他远程代理

可将 `scripts/remote-relay.py` 安装为 `~/.local/bin/si-notchctl`，权限设为 0700；创建权限为 0700 的 `~/.si-notch/run`，并在应用中填写绝对套接字路径。代理环境：

```sh
export SI_NOTCH_SOCKET="$HOME/.si-notch/run/events.sock"
export SI_NOTCH_CLI="$HOME/.local/bin/si-notchctl"
"$SI_NOTCH_CLI" emit '{"event":"agent.working","session_id":"remote-test","provider":"custom","title":"Remote test"}'
```

仅连接可信账户，它们可以发送事件与明确的决策请求。现有套接字不会被覆盖。连接失败时检查认证、主机密钥、转发策略和套接字占用情况。退出应用会停止所有隧道。[验证范围](parity.md)。
