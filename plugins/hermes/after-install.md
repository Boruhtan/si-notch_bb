# Connect this Hermes profile to si-notch

This observer reports profile presence and task activity. It does not run a second agent service, approve tools or submit replies. Continue only for the local/remote profile(s) the user selected.

1. Resolve this profile's actual `HERMES_HOME`. Read this plugin's `README.md` and only its own `si-notch.json` if present. On an update, keep `instanceId`, display name, text preference, helper/socket paths, unknown settings and `usage-outbox`. A working 1.12 observer also works with Mac app 0.4.31; no emergency reset or migration is needed.
2. If the profile is already configured and delivery works, keep its settings. For a new profile, ask one short question only for missing location, display name or text-sharing choice. Run this directory's `configure.py setup --name "Chosen name" --hide-text` unless the user chose text sharing. Scope every Hermes command to this profile with `-p PROFILE` or its exact `HERMES_HOME`.
3. Each local or remote profile needs a distinct stable ID. Setup creates it automatically. Never copy another profile's settings or pending usage queue. Use `setup --new-instance` only when the user explicitly selected a new clone whose ID was copied; do not rotate an existing profile's ID during an update.
4. On the local Mac, keep si-notch running and use its native `si-notchctl`. Standard app locations are discovered automatically. For a custom app location, use `setup --helper /absolute/si-notch.app/Contents/Helpers/si-notchctl` together with the chosen name. No SSH is needed for local profiles.
5. For a remote profile, give the user setup's absolute remote socket path and the SSH alias for **si-notch → Settings → Remote SSH → Connect**. One tunnel serves the host's profiles. Keep the remote socket path; do not create a second tunnel to the same endpoint or change the Mac's internal sockets.
6. Respect the install receipt and the user's enable choice. If enabling was requested and remains incomplete, enable only `si-notch` through the native CLI. Inspect activation; if reload is unavailable, finish the current turn and use a new session. Run `configure.py check` and allow one 30-second heartbeat interval. Report activation and acknowledged delivery separately from the user's verification in Agents. Run the bounded task smoke test only when requested.

Keep existing Hermes hooks, notify settings, models, providers, approval policy and services. Do not inspect credentials, histories or unrelated configuration. Do not remove an existing plugin before updating it. Back up its own settings/queue outside the plugin directory, use the reviewed pinned update from the same official source, and retain the installer's normal scan/consent checks. For a stale socket, show `repair-socket` preview and obtain permission before `--apply`; never remove an active socket.

For a complete multi-profile request, use [INSTALL_PROMPT.md](INSTALL_PROMPT.md) or [INSTALL_PROMPT.ru.md](INSTALL_PROMPT.ru.md). Русская инструкция также подходит для нескольких локальных профилей и нескольких SSH-хостов.
